# Security

## Supported code

Only the current `main` branch is maintained. This is a static client application with no authentication, user submissions, storage, or backend. Dependencies and the hosting configuration still require maintenance; this is not a security guarantee.

## Reporting

Use the repository's **Security → Report a vulnerability** option if private vulnerability reporting is enabled. If that option is unavailable, open an issue asking the maintainer for a private reporting channel without disclosing exploit details. Do not post secrets or exploitable details publicly.

Include the affected revision, reproduction steps, impact, and relevant browser information through the private channel. Reports are handled on a best-effort basis; no response-time commitment is made. Enable GitHub private vulnerability reporting and Dependabot alerts in repository settings.
